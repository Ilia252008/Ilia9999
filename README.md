## Описание проекта

Проект состоит из двух небольших графических программ на Python с библиотекой `tkinter`.
Первая программа («Двоичные числа») — интерактивный набор двоичных регистров: щелчком мыши
пользователь включает и выключает разряды, а программа считает получившееся число.
Вторая программа («Дождь») — анимация падающих капель, в которой дальние капли
меньше и движутся медленнее, благодаря чему создаётся ощущение глубины.



## Функциональные возможности

### Программа 1. Двоичные числа (`binary_numbers.py`)

#### Основной функционал
- 🖱️ Установка и снятие значения регистра щелчком мыши
- 🔢 Автоматический подсчёт и вывод десятичного значения двоичного числа
- ⚫ Визуальное отличие состояний: чёрный кружок — 1, белый кружок — 0

#### Дополнительный функционал
- 🔠 Отображение цифры (0 или 1) внутри каждого регистра

### Программа 2. Дождь (`rain.py`)

#### Основной функционал
- 💧 Постоянная генерация контрастных капель, равномерно движущихся вниз
- 🔁 Когда капля уходит за нижний край окна, вместо неё появляется новая сверху

#### Дополнительный функционал
- 🎚️ Настраиваемая плотность дождя (параметр `DROPS_COUNT`)
- 🌫️ Эффект трёхмерности: дальние капли короче, тоньше, светлее и движутся медленнее

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-логин>/<название-репозитория>.git
cd <название-репозитория>
```

Если репозитория нет, достаточно скачать файлы `binary_numbers.py` и `rain.py`
в одну папку и открыть эту папку в терминале.

### 2. Создание и активация виртуального окружения (необязательно)

Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

Не требуется: программы используют только стандартные библиотеки Python.

### 4. Запуск программ

Windows:
```bash
python binary_numbers.py
python rain.py
```

macOS/Linux:
```bash
python3 binary_numbers.py
python3 rain.py
```

### 5. Управление

**Двоичные числа**
- Щелчок левой кнопкой мыши по кружку — переключение разряда (0 ↔ 1)
- Крупное число под кружками — текущее значение в десятичной системе

**Дождь**
- Управление не требуется, анимация запускается сразу
- Плотность дождя меняется в начале файла `rain.py`: параметр `DROPS_COUNT`
  (например, 100 — редкий дождь, 600 — ливень)
- Закрытие окна завершает программу

## Пример использования

### Двоичные числа

```bash
python binary_numbers.py
```

1. Откроется окно с восемью белыми кружками и числом `0` под ними.
2. Щелчком по двум левым кружкам включаем два старших разряда: получается `11000000`,
   под кружками появляется число `192`.
3. Если включить все восемь кружков, получится `11111111`, то есть число `255`.
4. Повторный щелчок по кружку снова делает его нулём, число пересчитывается.

### Дождь

```bash
python rain.py
```

1. Откроется окно со светлым фоном, в котором падают фиолетовые капли.
2. Крупные и тёмные капли находятся «ближе» и падают быстрее,
   светлые и короткие — «дальше» и падают медленнее.
3. Чтобы изменить плотность, откройте `rain.py`, поменяйте значение `DROPS_COUNT`
   и запустите программу заново.
